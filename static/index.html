How it works

1. Scan

Select directory records, upload completed Excel templates, or enter official websites. Pause and resume from Running scans.

2. Review

Compare Old and New. Open Source & route to check the facility, exam, contrast, date and included fees. Missing data means unknown.

3. Apply

Approve or reject each update. Approval alone does not change the directory. Apply approved updates to save. Approve replacement explicitly replaces an existing field; stale values stay protected. Approve evidence only reviews the source finding.

4. Export or undo

Download Excel for grouped details and yellow old/new highlights. CSV includes all fields. Undo applied changes in Change history, newest first.

Coverage

Supports HTML, JavaScript rendering, scanned PDF OCR and supported CMS cash-price files up to 100 MB. OCR prices need visual review. No login flows, CAPTCHA solving or interactive estimator forms. No page-count or link-depth limit. External pricing hosts require a separate scan.

Contacts and location leads need branch verification. Repeated source checks do not guarantee the final bill. The original CSV stays unchanged.
